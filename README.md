# water-data
water data stations

## Setup

Install the required R package:

```r
source("setup.R")
```

Or manually:

```r
install.packages("dataRetrieval")
```

## Usage

Run the example water data retrieval script:

```r
source("water_data.R")
```

The [`dataRetrieval`](https://doi-usgs.github.io/dataRetrieval/) package provides access to USGS and EPA water data.
