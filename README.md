# water-data
Water data stations using the USGS `dataRetrieval` R package.

## Requirements

- R (>= 3.5)
- [`dataRetrieval`](https://cran.r-project.org/package=dataRetrieval) package

## Usage

Run the script to install the package and retrieve water data:

```r
source("water_data.R")
```

Or install the package manually and then run the script:

```r
install.packages("dataRetrieval")
source("water_data.R")
```
